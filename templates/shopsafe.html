how it works

Four checks. One trust score.

Every scan runs the same forensic pass a security analyst would — condensed into seconds.

01 / SSL

HTTPS Verification

Checks whether the website uses a valid, unexpired SSL certificate to protect your personal information in transit.

02 / SCORE

Trust Score

Calculates a composite trust score from security posture, domain reputation, and overall site credibility.

03 / RISK

Scam Detection

Flags phishing pages, cloned checkout flows, and fake shopping portals using known scam signatures.

04 / DOMAIN

Domain Analysis

Inspects domain age, registration details, and blacklist status to confirm the store is what it claims to be.
